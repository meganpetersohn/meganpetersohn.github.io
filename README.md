# meganpetersohn.github.io

Personal website of Megan Petersohn, built with [Quarto](https://quarto.org).

- Source: the `.qmd` files and `_quarto.yml` in this folder.
- Rendered site: `docs/` (GitHub Pages serves it: Settings > Pages > Deploy from a branch > `main` / `/docs`).
- To update: edit a `.qmd` file, run `quarto render`, and push. Figures for the wolf pup page live in `projects/snf-wolf-pups/figs/`.
